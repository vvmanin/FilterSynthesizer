## Details for #1

- Spec: `_custom_spec["roots"]` gains `k_form` (`"K"` | `"C"`, default `"K"` in
  `custom_tf.default_spec()`). The number stays in `roots["K"]`; with
  `k_form == "C"` it is read as C. A missing `k_form` (older session state)
  reads as K. Switching the radio reinterprets the typed number; it does not
  convert it.
- `custom_tf.parse_spec` (roots branch): `K = 1 / C`; a zero/blank C errors as
  "C must be a nonzero number." in As-entered mode and counts as 1 in Normalize
  mode, like K. `k_entered` stays in the gain sense (K), so the diagnostics and
  `fill_custom_k` are unchanged except that `fill_custom_k` shows 1/K in C form.
- Widget key `custom_kform_roots`, reset to K by "Reset to the example".
- Other forms (Coefficients, f₀/Q, Tietze–Schenk) are unchanged.

## Checks
